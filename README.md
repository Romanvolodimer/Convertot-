# CSV → Hourly Excel Converter

Статичний вебконвертер для CSV-файлів з 30-хвилинними значеннями.

## Формат вхідного CSV

Очікуваний формат:

```csv
Date,Timezone,Value
2026-08-04T00:00:00.000+03:00,+03:00,199.2114715576172
2026-08-04T00:30:00.000+03:00,+03:00,90.91275024414062
```

Конвертер об'єднує:

- 00:00 + 00:30 → 00:00
- 01:00 + 01:30 → 01:00
- 02:00 + 02:30 → 02:00
- тощо.

Результат завантажується як `.xlsx`.

## Запуск локально

Просто відкрий `index.html` у браузері.

## GitHub Pages

1. Створи репозиторій на GitHub.
2. Завантаж `index.html`, `style.css`, `app.js`.
3. Відкрий Settings → Pages.
4. У Build and deployment вибери `Deploy from a branch`.
5. Вибери `main` і `/ (root)`.
6. Збережи налаштування.
7. GitHub видасть адресу сайту.

## Приватність

CSV не відправляється на сервер. Файл читається та обробляється у браузері. Для генерації XLSX використовується SheetJS із CDN.
